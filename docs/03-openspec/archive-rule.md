# Archive Rule

Completed or superseded proposals and designs must be archived in `docs/99-archive/`.

## When to Archive

- A proposal is implemented and verified.
- A design is superseded by a new one.
- A spike or experiment is abandoned.

## Format

Prefix archived files with date:

```text
docs/99-archive/YYYY-MM-DD-proposal-name.md
```

## Content

Each archived file must include:

- Original title and date
- Reason for archiving
- Link to the current approach (if superseded)
