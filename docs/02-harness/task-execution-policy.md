# Task Execution Policy

## Scope

Each task should be small enough to implement, test and review in one focused session.

## Task Format

Use the Tasks rule in `docs/03-openspec/tasks-rule.md`.

## Execution Order

1. Read context
2. Propose plan
3. Implement
4. Test
5. Update docs and current-state.md

## Stopping Conditions

Stop and report when:

- the task scope becomes unclear
- a storage contract change is required but not documented
- a security or approval policy implication is discovered
- tests fail and cannot be fixed within the task scope
